# PORTAL DARK

> Um projeto independente dedicado ao aprendizado, à criação e à organização de scripts e interfaces em Luau para o ecossistema Roblox.

## Sobre o projeto

O **PORTAL DARK** nasceu da vontade de explorar programação, desenvolver ideias próprias e transformar conceitos em ferramentas bem organizadas. O repositório reúne o desenvolvimento do projeto, suas experiências, documentação e futuras melhorias.

## Destino

O objetivo é construir um projeto cada vez mais organizado e acessível, com interfaces claras, código bem estruturado e documentação que ajude outras pessoas a entender como ele funciona.

O foco é o desenvolvimento com **Roblox Studio e Luau**, incluindo protótipos de interface e recursos destinados a experiências próprias ou a usos permitidos pelas regras das plataformas. O projeto não é oficial nem possui afiliação com a Roblox Corporation.

## Motivo da criação

Este projeto foi criado para:

- Praticar e aprofundar conhecimentos em programação Luau.
- Experimentar ideias de interface e experiência do usuário.
- Organizar scripts, versões e documentação em um só lugar.
- Aprender com testes, correções e sugestões da comunidade.
- Compartilhar o progresso e receber contribuições construtivas.

## Motivação

A motivação do PORTAL DARK é aprender construindo. Cada atualização representa uma oportunidade de melhorar o código, resolver problemas e descobrir novas possibilidades. A ideia é evoluir junto com a comunidade, mantendo o projeto transparente e aberto a sugestões.

## Como contribuir

Sugestões, relatos de bugs e ideias são bem-vindos! Você pode abrir uma **Issue** descrevendo o que encontrou ou sugerindo uma melhoria. Contribuições devem respeitar as regras do Roblox e os direitos de terceiros.
